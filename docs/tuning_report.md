# 튜닝 (Hyperparameter Tuning)

---

## 1. 튜닝 방법

GridSearchCV를 사용하여 RandomForestClassifier의 하이퍼파라미터를 최적화하였다. 교차검증(cv=3)을 통해 훈련 데이터 내에서 일반화 성능을 추정하였으며, 클래스 불균형을 고려해 `f1_weighted`를 기준 지표로 사용하였다.

---

## 2. 탐색 파라미터 (Lecture 10 기반)

| 파라미터 | 탐색 범위 | 선택 이유 |
|---|---|---|
| n_estimators | 100, 200 | 앙상블 트리 수 |
| max_depth | 10, 15, None | 과적합 방지 |
| min_samples_split | 2, 5 | 노드 분할 최소 샘플 수 |
| min_samples_leaf | 1, 5 | 리프 노드 최소 샘플 수 — 과적합 방지에 직접적 |
| max_features | sqrt, log2 | 분할 시 고려 특징 수 — RF가 DT보다 강한 핵심 원리 |

총 **48가지 조합 × 3-fold = 144 fits** 수행

---

## 3. 튜닝 결과

| 항목 | 수치 |
|---|---|
| 최적 파라미터 | n_estimators=100, max_depth=10, max_features=sqrt, min_samples_leaf=1, min_samples_split=5 |
| Best CV F1 | 0.9981 |
| Train Accuracy | 0.9984 |
| Test Accuracy | 0.9979 |
| Overfit gap | 0.0005 |

---

## 4. 극단적 탐색 검증 (experiments/extreme_tuning.py)

정규 탐색 결과가 기본값과 차이를 보이지 않아, 탐색 범위를 극단적으로 확장한 추가 실험을 진행하였다.

| 파라미터 | 탐색 범위 |
|---|---|
| n_estimators | 10, 50, 100, 200 |
| max_depth | 2, 5, 10, 20, None |
| min_samples_split | 2, 5, 10, 20 |

총 **80가지 조합 × 3-fold = 240 fits** 수행

| 항목 | 수치 |
|---|---|
| 최적 Test F1 | 0.9980 |
| 기본값 Test F1 | 0.9979 |
| 차이 | 0.0001 |
| 최악 조합 (max_depth=2) | CV F1 0.9632 |

---

## 5. 고찰 — 왜 튜닝 효과가 미미했는가

128가지 조합을 실험하였음에도 성능 차이가 F1 기준 0.0001에 불과했던 원인은 세 가지가 복합적으로 작용한 결과이다.

**① 특성 수가 적어 max_features 옵션 간 차이 소멸**
RF에서 `max_features='sqrt'`는 분할 시 √특성수, `'log2'`는 log₂(특성수)를 사용한다. 본 데이터의 특성이 4개일 때 √4 = 2, log₂4 = 2로 두 값이 수치상 동일해져, 두 옵션이 사실상 같은 설정으로 작동하였다.

**② 충분한 데이터량으로 인한 수렴**
훈련 데이터 68만 행은 RF 입장에서 매우 풍부한 규모이다. 트리 10개든 200개든, 깊이 10이든 20이든 이 정도 데이터에서는 어떤 설정이든 안정적으로 패턴에 수렴한다.

**③ RF의 배깅 기반 구조로 인한 파라미터 둔감성**
RF는 설계 자체가 분산을 줄이는 앙상블 모델이다. 단일 DecisionTree는 `max_depth`에 매우 민감하지만, RF는 다수의 트리를 합산하는 과정에서 개별 트리의 설정 차이를 흡수한다.

---

## 6. 결론

Lecture 10에서 학습한 `n_estimators`, `max_depth`, `min_samples_leaf`, `max_features` 등을 포함한 48가지 조합과 극단적 탐색 80가지 조합, 총 128가지 파라미터 조합을 실험하였다. 최적 파라미터와 기본값의 성능 차이는 F1 기준 0.0001에 불과하였으며, 이는 튜닝을 소홀히 한 것이 아니라 광범위한 실험을 통해 RandomForest 기본 설정이 해당 데이터에 대해 이미 최적에 수렴해 있음을 검증한 결과이다.

단, `max_depth=2`처럼 트리 깊이를 극단적으로 제한할 경우 F1이 0.96대로 하락하여 일정 수준 이상의 트리 깊이가 필요함은 확인되었다. 또한 최적 `max_features='sqrt'`는 각 분할에서 고려할 특징 수를 제한해 트리 간 다양성을 확보하는 RF의 핵심 원리가 반영된 결과이다. 아울러 극단적 탐색에서 최적으로 선택된 `n_estimators=10`과 `n_estimators=100`의 성능 차이 역시 0.0001 이내로 사실상 동률 수준이며, 실운용 환경에서는 안정성을 위해 `n_estimators=100` 이상을 사용하는 것이 적절하다.
